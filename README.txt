MOTO FINANCE — versión 0.1
Costo de servidor de datos: Q0. Los movimientos se guardan en IndexedDB del dispositivo.
PUBLICACIÓN: subir todos los archivos de esta carpeta a un hosting estático gratuito con HTTPS (por ejemplo GitHub Pages). No subir estados de cuenta ni respaldos: solo el código.
INSTALACIÓN EN IPHONE: abrir la URL en Safari > Compartir > Añadir a pantalla de inicio.
PRIMER USO: ahorro inicial Q2,000, meta Q50,000, ahorro Q1,000/quincena y préstamo máximo Q13,000 son valores editables.
IMPORTANTE: hacer respaldo JSON semanal en Archivos/iCloud Drive; el almacenamiento del navegador puede borrarse. No hay sincronización automática entre dispositivos.
TARJETA FAMILIAR: registrar consumos como Gasto/Tarjeta familiar. Al pagar la tarjeta, usar Transferencia/Pago tarjeta familiar para evitar doble conteo.
GASTOS COMPARTIDOS: activar casilla e indicar tu parte. Los reintegros que recibas de tu esposa pueden registrarse como ingreso/reintegro, pero el tablero excluye esos reintegros de los ingresos recurrentes para no inflarlos.
NOTA: primera versión manual; no importa estados bancarios ni conecta con bancos.
